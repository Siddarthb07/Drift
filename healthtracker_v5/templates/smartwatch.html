  1. Go to dev.fitbit.com/apps/new and create a new app
  2. Set OAuth 2.0 Application Type to Personal
  3. Set Callback URL to: http://localhost:5001/oauth/callback/fitbit
  4. Note down your Client ID and Client Secret
  5. Set environment variables before running the app: 
    export FITBIT_CLIENT_ID="your_id_here"
export FITBIT_CLIENT_SECRET="your_secret_here"
  6. Restart the app and click "Connect Fitbit" above
⚠ Fitbit's Personal access tier allows up to 150 API calls/hour and is free for personal use.
  1. Go to Google Cloud Console and create/select a project
  2. Enable the Fitness API in APIs & Services → Library
  3. Go to OAuth consent screen: set type to External, add your email as a test user
  4. Go to Credentials → Create Credentials → OAuth 2.0 Client ID
  5. Application type: Web application
  6. Add Authorised Redirect URI: http://localhost:5001/oauth/callback/googlefit
  7. Set environment variables: 
    export GOOGLE_CLIENT_ID="your_client_id.apps.googleusercontent.com"
export GOOGLE_CLIENT_SECRET="your_secret"

  1. Go to Garmin Developer Portal
  2. Apply for access to the Garmin Health API (review process, 1–2 weeks)
  3. Once approved, create an app and obtain OAuth 1.0a consumer key and secret
  4. Set environment variables: 
    export GARMIN_CLIENT_ID="your_consumer_key"
export GARMIN_CLIENT_SECRET="your_consumer_secret"
ℹ Garmin uses OAuth 1.0a which requires a slightly different flow. The current implementation uses OAuth 2.0 as a placeholder — full 1.0a support is on the roadmap.
